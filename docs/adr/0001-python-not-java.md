# Use Python, not Java

The assignment allows Java or Python. We chose Python because the implementing author is not fluent in Java, and switching languages later would rewrite the model package, tests, manuals, and design diagrams together.

Java would map more directly onto the assignment's class-diagram and JUnit examples. That gain is documentation convenience, not extra marks: the required user stories, `model` package, standard-library-only rule, and MVC-shaped design can be satisfied in Python with `unittest` and a real `model` package.

**Status**: accepted
