# No recurring Event series

Appendix B names four PIR types: Note, Task, Event, Contact. It does not mention recurrence, RRULE, or this-vs-series edit. Extra features get no extra credit and would add a second lifecycle (instance vs series) that is easy to specify incompletely.

A weekly class is several Events that share a description and have different Ids and starting times. Modify and delete always target one Id.

**Status**: accepted
